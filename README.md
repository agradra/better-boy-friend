# BetterBoyFriend

## 지원 사양
* **최소 안드로이드 버전**: Android 12 (API 31) 이상

---

## 필수 시스템 권한 설정
설치하고 앱 처음 켤 때 트리거 탭 상단 카드나 시스템 설정에서 아래 권한들을 전부 허용해줘야 함.  
안 켜면 백그라운드 감지나 팝업 안 뜸.

1. **다른 앱 위에 표시 (오버레이 권한)**:  
   * 카톡이나 유튜브 볼 때 그 위에 팝업 띄우려면 무조건 필수.
2. **접근성 권한 (Accessibility)**:  
   * 설치된 앱 목록에서 `BetterBoyFriend 앱 실행 감지` 찾아서 켜야 함.  
   * 유튜브, 인스타, 배민 등 특정 앱 켜는 순간 감지하는 용도.
3. **알림 접근 허용 (Notification Listener)**:  
   * `BetterBoyFriend 알림 감지` 허용 필요.  
   * 카톡, 문자, 인스타 DM 올 때 상대방 이름 감지용.
4. **전화 권한 (Phone State)**:  
   * 전화 올 때 발신자 이름/번호 감지용.
5. **배터리 최적화 예외 (선택 권한 권장)**:  
   * 백그라운드에서 시스템이 앱 죽이지 못하게 '배터리 사용량 무제한'으로 설정해두는 것 추천.

## APK 다운로드 및 설치
* 깃허브 저장소 우측 **Releases** 탭 들어가서 `BetterBoyFriend.apk` 다운받고 폰에서 설치하면 됨.
* 별도 서명 작업 없이 바로 설치 가능함.

---

## ⚠️ 설치 시 주의사항 ("기기 보호를 위해 앱 차단됨" 해결법)
* 설치할 때 **"기기 보호를 위해 앱 차단됨"** 또는 **"금융 사기 위험"** 경고가 뜨며 설치 버튼이 안 나오는 경우:
  * 앱 실행 감지(접근성) 및 알림 권한 때문에 구글 Play 프로텍트가 외부 APK를 오인하여 강제 차단하는 현상임.
  * **해결 방법**:
    1. 스마트폰 **[Play 스토어]** 앱 실행 ➡️ 우측 상단 **[내 프로필]** 터치
    2. **[Play 프로텍트]** 메뉴 ➡️ 우측 상단 **[⚙️ 설정]** 터치
    3. 맨 위 **[Play 프로텍트로 앱 검사]** 항목을 잠시 **'끄기(OFF)'**
    4. 끈 상태에서 APK 파일을 다시 눌러서 설치 진행
    5. *(설치 완료 후 Play 프로텍트 검사는 다시 켜도 앱 사용에 문제없음)*
* 갤럭시 사용자의 경우 **설정 ➡️ 보안 및 개인정보 보호 ➡️ [보안 위험 자동 차단]**도 잠시 '사용 안 함'으로 꺼야 할 수 있음.
